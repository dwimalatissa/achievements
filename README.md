# achievements

A scratch repository for earning GitHub profile achievements.

## Target badges

- **YOLO** — merge a pull request without a review
- **Quickdraw** — close an issue or pull request within 5 minutes of opening it
- **Pull Shark** — open pull requests that get merged (2 for the base badge)
- **Galaxy Brain** — get an accepted answer on a discussion

## Notes

Achievements only count activity in **public** repositories, and require
*Settings → Public profile → Show Achievements on my profile* to be enabled.
